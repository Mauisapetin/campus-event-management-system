# Campus Event Management System

## About the Project
Campus Event Management System is a mobile application designed to help students and event organizers in our school. Students can easily browse upcoming events, check details, and confirm their attendance. Organizers can create and manage events, track participants, and generate QR codes for registration.

This is our capstone project.
